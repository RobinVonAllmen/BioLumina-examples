# BioLumina Examples

Version: 1.0.0

This package contains example image and video data intended for use with **BioLumina**. The examples demonstrate several types of biological imaging data and supported asset formats.

## Contents

### `Picture1.png`

A single-tile microscope image showing pollen grains obtained from honey.

### `test.mp4`

A short video sequence showing halfbeaks (fish) in a natural river environment.

### `image_sequence/`

A folder containing multiple views from a stereo microscope image sequence of planktonic foraminifera as PNG format.

### `dzi_example/`

A Deep Zoom Image (DZI) formatted image pyramid containing a whole pollen reference sample of *Neottia nidus-avis*.

The DZI entry point is:

`RS007_048_neottia nidus-avis_large_image_20X_z000.dzi`

Associated DZI pyramid tiles are contained within the corresponding DZI asset directory.

## Purpose

These files are provided as example assets for testing, demonstrating, and developing BioLumina functionality, including support for:

- standard raster microscope images;
- video data;
- image sequences;
- microscopy imagery;
- biological reference specimens; and
- Deep Zoom Image (DZI) pyramids.
